# Smart Expense & Budget Tracker — UI Guidelines

## 1. UI Goal

The UI should look modern, clean, dashboard-oriented, and easy to scan. It should feel like a finance product, not a random student project.

## 2. Core Screens

* Login
* Signup
* Dashboard
* Add Expense form
* Budget summary cards
* Notifications section

## 3. Layout Style

* Use a clean dashboard layout
* Keep spacing consistent
* Avoid overcrowding cards and charts
* Use clear section headings

## 4. Component Expectations

* Reusable button component style
* Reusable input field styling
* Reusable card styling for metrics and summary blocks
* Notification items should be visually separated and easy to scan

## 5. Dashboard Expectations

Dashboard should include:

* Total expenses card
* Budget remaining card
* Monthly budget usage card
* Category expense chart
* Monthly expense trend chart
* Recent notifications section

## 6. UX Rules

* Every form should have validation feedback
* Buttons should show loading state when submitting
* Error messages should be visible and readable
* Empty states should not look broken

## 7. Responsive Behavior

* Dashboard should work on desktop first
* Tablet layout should still be usable
* Mobile layout should stack cards and charts cleanly

## 8. Styling Direction

Use a professional dashboard feel:

* clear typography
* consistent card spacing
* soft shadows or subtle borders
* readable chart areas
* not too many random colors

## 9. Code Organization Expectations

Frontend code should separate:

* pages
* components
* services
* hooks or utilities where useful
